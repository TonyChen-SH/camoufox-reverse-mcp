# Camoufox Reverse MCP

Local collection, offline analysis and read-only MCP tools for native Camoufox API traces.

The implementation is developed on [`codex/trace-analysis-pilot`](https://github.com/TonyChen-SH/camoufox-reverse-mcp/tree/codex/trace-analysis-pilot) and reviewed through pull requests. Reports describe observed calls and missing data; they do not infer a website's server-side detection decisions.

Companion native source pilot: [camoufox-reverse](https://github.com/TonyChen-SH/camoufox-reverse).
